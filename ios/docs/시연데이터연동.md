# 시나리오 데이터 연동

현재 지도 노출·회색 판정·실제 조사 장소와 앱 확인 방법은
[장소 동반 판정 검증](장소동반판정검증.md)을 참고합니다.

실서버 시연은 보호자 테스트 계정에 몽이만 등록된 상태로 시작합니다.
이는 초기 시드 기준이며 사용 중인 배포 계정을 강제로 초기화하지 않습니다.
계정 정보와 QR은 백엔드 시드 실행 결과로 전달받습니다. 콩이는 8kg 믹스견,
매너벨트·리드줄 보유로 시연 중 등록합니다.

업체 웹은 이메일과 휴대전화 로그인을 모두 지원합니다. 사용자 앱은 보호자 휴대전화 로그인을 유지합니다.

- 장소 카드의 category와 상세의 imageUrls·phoneNumber·businessHours를 표시합니다.
- 최대 체중은 실제 응답 값을 표시하며, 야외 구역 판정은 별도로 안내합니다.
- 챗봇에 `콩이 프로필에 유모차 추가`를 보내면 서버의 확인 버튼이 나타납니다.
  확인 전에는 정보가 바뀌지 않으며, 확인 후 반려견 목록을 다시 불러옵니다.
- 업체 정책 편집은 실내·야외 조건과 적용 시작일을 전송합니다.
- 업체 웹의 행사 목록은 보호자 전용 API 대신 `/business/events`를 사용합니다.
- 문의·근거 파일은 `/files`로 업로드한 뒤 안정적인 참조를 보관합니다.

자세한 시드·초기화 방법은 BE의 `docs/DEMO_SCENARIO.md`를 참고하세요.
실기기에서는 지도 선택 변경, 사진 표시, 챗봇 확인, QR 카메라 촬영을 추가 확인합니다.
