# 사용자 앱 전달 사항 (2026-11-05 작성, 11-12 갱신, 이채린)

## 백엔드에게

11-12에 BE 저장소 코드를 직접 읽고 앱을 맞췄어요. 확인 · 요청할 것은 `docs/백엔드연동.md` 3절에 있어요.

## 차명실 님에게 (업체 관리자 웹 · 관리자)

- 앱은 iOS 따로, 웹은 React 따로 — 코드 공유는 없고 **규칙만** 맞춰요.
- 맞출 것: 오류 코드 이름 · 문구, 판정 상태값(서버 기준 `ENTRY_OK · PREPARE · CHECK_REQUIRED · ENTRY_DENIED`), 증빙 상태값(`VERIFIED · NEEDS_MORE · REUPLOAD · OPERATOR_REVIEW`), 날짜 표기.
- 팀이 모일 때 정할 디자인 통일 5건(결정사항.md '미정'): 판정 칩 모양, 웹 로고, 글꼴(Pretendard 추천), 업체 센터 주 색, 오류 색.
- 저장소: `Advanced-Swiftly/FE` 안에서 폴더 나누기 제안 → `ios/` (사용자 앱), `web/` (업체 관리자 웹 · 관리자).

## 팀 전체

- 저장소: 사용자 앱은 `FE/ios/`. Claude가 직접 올리려면 조직에 Claude GitHub 앱 허용이 필요해요.
- iOS 빌드는 Mac + Xcode 16 + XcodeGen.
- 번들 ID `com.advancedswiftly.pawfit` (임시). Apple 개발자 팀 · 실기기 테스트 계정 정해야 해요.
- Google Maps SDK API 키(지도 화면 시작 전에 필요), 네이버 지도 앱 연동은 키 없이 URL 스킴(`nmap://`)으로.

## 앱에서 임시로 정한 것 (확인 부탁)

| 항목 | 임시로 한 것 | 근거 |
| --- | --- | --- |
| [로그인] 빈 칸일 때 | 버튼은 그대로 두고, 누르면 빈 칸으로 커서 이동 | 캔버스에 비활성 모습이 없음 |
| 네트워크 오류 문구 | "인터넷 연결을 확인해 주세요" | 명세서에 없음 |
| 로고 크기(S1) | 95×95 비율 유지 | 캔버스는 103×95로 살짝 늘어나 있음 |
| 시작 화면 최소 표시 | 0.7초 | 로고가 깜빡 지나가지 않게 |
| 다크 모드 | 라이트 고정 | 다크 모드 검토 중 |
| 판정 칩 | 색 원 + 흰 모양 + 글자 캡슐 (임시 크기) | 지도 화면 작업 때 캔버스 값으로 맞춤 |
