# 실제 장소와 동반 판정 연동 검증

기준: 2026-11-18 배포. 실제 장소 결과와 검증 시점의 건수는
[BE 배포 장소 결과](https://github.com/Advanced-Swiftly/BE/blob/f97200624e648387a78c46bb313c511e6be7e487/docs/PLACE_DATA_RELEASE.md)를
참고합니다. 링크는 검토 중인 문서 커밋에 고정되어 있으며 [BE #68](https://github.com/Advanced-Swiftly/BE/issues/68)에서 연결된 PR을 확인할 수 있습니다.

## 지도 노출과 회색의 의미

지도에 나오는 장소는 반려견 동반 가능이 확인된 장소입니다. 회색 `CHECK_REQUIRED`는
동반 여부 자체가 미확인이라는 뜻이 아니라, 선택 반려견의 입장을 확정할 세부 조건이
부족하다는 뜻입니다. 동반 자체가 미확인이거나 동반 불가인 장소는 서버가 지도·검색·상세에서 제외합니다.

| 입력과 조건 | 기대 표시 |
| --- | --- |
| 동반 가능 확인, 세부 조건 부족 | 동반 여부 가능, 미확인 조건은 확인 필요, 회색 |
| 동반 가능 확인, 알고 있는 체중 제한 위반 | 입장 불가, 해당 체중 결과는 빨강 |
| `7kg 미만`, 반려견 7kg | 제한 위반. `7kg 이하`로 바꿔 표시하지 않음 |
| 백신 필수의 구체 종류·검증 조건 미확인 | 접종 확인 완료로 표시하지 않음 |
| 준비물 여러 개지만 AND/OR 미확인 | 모두 필수 또는 택일로 추정하지 않음 |
| 동반 자체가 미확인 또는 불가 | 지도·검색에서 제외, 상세 요청은 404 |

이미 동반 가능한 업체라도 특정 반려견의 체중·견종 등 확인된 제한 때문에 빨강일 수 있습니다.
판정 심각도는 `ENTRY_DENIED > CHECK_REQUIRED > PREPARE > ENTRY_OK`이며, 함께 가요의
결과는 서버 판정을 사용합니다. 앱이 판정을 다시 계산하거나 빈 조건을 제한 없음으로 바꾸지 않습니다.

## 상세 응답과 표시

| 필드 | 의미와 앱 처리 |
| --- | --- |
| `admissionConfirmed` | 반려견 동반 확인 여부. 구버전 응답 호환을 위해 Optional |
| `policyDetailsComplete` | false이면 모르는 체중·견종·준비물·접종 조건을 충족으로 표시하지 않음 |
| `maxWeightKg` | 확인된 체중 상한. 없으면 제한 없음이라고 가정하지 않음 |
| `maxWeightExclusive` | true이면 미만, false이면 이하 |
| `requiredEquipmentCodes` | 명확히 구조화된 필수 준비물. 부분 정책에서는 다른 조건이 남아 있을 수 있음 |
| `unrestrictedFields` | 서버가 제한 없음을 확인한 항목. 부분 정책의 빈 배열은 모두 제한 없음이 아님 |
| `reasons` | `POLICY_DETAILS_UNCONFIRMED`를 준비물 이름으로 해석하지 않음 |
| `policySource`, `confirmedOn` | 원문 조건과 확인일을 확인할 근거 |

기름칠을 몽이 5kg 기준으로 확인한 상세 응답의 주요 필드 예시입니다. 전체 응답을 대체하는
고정 fixture가 아니며, ID는 이 배포 환경에서만 유효합니다.

```json
{
  "placeId": "PUBLIC:6323",
  "name": "기름칠",
  "verdict": "CHECK_REQUIRED",
  "admissionConfirmed": true,
  "policyDetailsComplete": false,
  "maxWeightKg": 7,
  "maxWeightExclusive": true,
  "unrestrictedFields": []
}
```

## 실제 데이터와 확인 순서

| 출처 | DB 보관 | 지도 노출 대상 |
| --- | ---: | ---: |
| 팀이 직접 조사한 실제 장소 | 41 | 41 |
| 한국관광공사 서울 공공 장소 | 3,159 | 997 |
| 시연용 가상 업체 | 6 | 4 |
| 합계 | 3,206 | 1,042 |

공식 동반 상세 API의 429 제한으로 나머지 공공 장소 2,162곳은 확인 보류 상태입니다.
목록에 있다는 이유만으로 노출하지 않습니다. 화면의 핀 수는 위치·반경·카테고리·반려견에 따라
달라지고 서버는 최대 500곳을 반환합니다. 표의 건수를 앱 상수나 지도 목록 개수로 사용하지 않습니다.
2026-11-18 성수 좌표 37.5446, 127.0557, 반경 1.5km, 몽이 기준 지도 조회는 68곳이었습니다.

1. 최신 `develop`을 받고 `ios`에서 `xcodegen generate` 후 앱을 다시 빌드합니다.
2. `PAWFIT_USE_MOCK_API=NO`와 배포 API 주소를 확인하고 본인 보호자 계정으로 로그인합니다.
3. 반려견 목록을 먼저 확인합니다. 기존 배포 계정을 임의 초기화하거나 몽이만 있다고 가정하지 않습니다.
4. 성수 위치에서 카페·식당 필터를 확인하고 실제 조사 장소 이름으로 검색합니다.
5. 예를 들어 `PUBLIC:6321` 88스테이크 서울숲 상세에서 동반 가능과 미확인 조건이 구분되는지 확인합니다.
6. `PUBLIC:6323` 기름칠과 `PUBLIC:6336` 빌라드블루 성수의 `7kg 미만` 표시를 확인합니다.
7. 기존 가상 업체 `STORE:1`, `STORE:2`가 지도·검색에 나오지 않고 직접 상세 요청도 404인지 확인합니다.

검증 API는 `/places`, `/places/map`, `/places/{placeId}`, `/places/{placeId}/entry-judgments`입니다.
반려견 ID는 로그인한 보호자 본인의 ID를 사용합니다. 401·403을 우회하거나 다른 보호자의 ID를
테스트용으로 사용하지 않습니다. 로그인 비밀번호·토큰·QR 원본은 이 문서나 PR에 붙이지 않습니다.

## 시연 초기 상태와 검증 범위

새 초기 시연은 몽이 5kg으로 시작하고 콩이를 8kg·매너벨트·리드줄 보유로 등록합니다.
현재 사용 중인 계정의 상태는 원래 시연 초기 상태와 다를 수 있습니다.
테라스 오브 성수는 10kg 이하·유모차 조건이라 콩이 유모차 추가 전 준비 필요를 시연할 수 있습니다.
챗봇 준비물 변경은 서버 확인 버튼을 눌러야 반영됩니다.

실제 41곳은 몽이 기준 상세·각 좌표 30m 지도·업체명 검색·카테고리 필터에서 모두 확인했습니다.
이는 API 검증이며 설치 앱의 실기기 화면·QR 카메라·모든 화면 크기 확인을 대신하지 않습니다.
로컬에는 Xcode가 없어 iOS 실행 검증은 GitHub macOS CI 결과를 사용했습니다.
