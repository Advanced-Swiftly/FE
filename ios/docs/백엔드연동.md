## 2. 백엔드 규칙 (앱이 맞춘 것)

- 주소 앞부분 `/api/v1`, `Authorization: Bearer <accessToken>`. 액세스 30분 · 리프레시 30일(서버 기본값).
- 오류 응답은 평평한 객체:
  `{ "timestamp", "status", "code", "message", "path", "requestId", "fieldErrors": { "필드": "사유" } }`
  - 앱은 `code`로 문구를 고른다. 서버 `message`는 대부분 "요청을 처리할 수 없습니다."라 쓰지 않는다.
  - 공통 코드: `COMMON_001`(형식 오류) · `COMMON_002`(없음) · `AUTH_001`(토큰 없음 · 만료) · `AUTH_002`(권한 없음) · `TOO_MANY_REQUESTS` · `COMMON_500`
- ID는 숫자(Long) — 앱은 `Int64`. 업체 `placeId`만 문자열.
- 로그인 요청 `{ phoneNumber, password, deviceToken? }`, 응답 `{ user: { userId, role, name }, accessToken, refreshToken }`.
- 역할 `GUARDIAN · BUSINESS · OPERATOR`. 앱은 **GUARDIAN만** 받고, 다른 역할이면 토큰을 저장하지 않고 "보호자 계정으로 로그인해 주세요".
- 판정 값: `ENTRY_OK · PREPARE · CHECK_REQUIRED · ENTRY_DENIED` (기능 명세서의 UNKNOWN · NO_ENTRY 대신). 나쁜 순서 ENTRY_DENIED > CHECK_REQUIRED > PREPARE > ENTRY_OK는 우리 결정(빨강 > 회색 > 노랑 > 초록)과 같다.
- 휴대폰 번호는 010만 받는다(`^(?:\+82[- ]?|0)10[- ]?\d{4}[- ]?\d{4}$`).
- 시연 서버 휴대폰 인증번호 **123456 고정**.

## 3. 백엔드에 확인 · 요청할 것

| # | 내용 | 이유 |
| --- | --- | --- |
| 1 | 시연 서버 주소가 `https://pawfit-api.onrender.com`이 맞는지, 보호자 테스트 계정 | render.yaml의 서비스 이름으로 짐작한 주소 |
| 2 | 비밀번호 규칙 '영문 + 특수기호 + 8자 이상'을 서버에서도 검사 | 지금 서버는 8~72자만 검사 (10-28 결정) |
| 3 | 로그인 응답에 `hasDogs`(또는 반려견 수) | 가입 · 로그인 직후 반려견 등록 안내에 필요. 없으면 `GET /dogs`를 한 번 더 부름 |
| 4 | `GET /users/me`에 배송지 | 보호자 계정 관리 · 댕댕로드 응모에 배송지가 필요한데 지금 응답에 없음 |
| 5 | 이벤트(댕댕로드)가 분기 단위인지 | 10-27 결정: 분기 4개, 분기 마지막 날 마감 |
| 6 | 공공데이터 장소를 사용자 앱(챗봇 답변 → 장소 상세)에서 볼 API | 지금은 관리자용 `/admin/public-facilities`만 있음 |
| 7 | 반려견 프로필 사진 올리기 | 반려견 API에 사진 필드 · 업로드가 안 보임 |

## 5. 차명실 님(웹)과 맞출 것

- 판정 값이 서버에서 `CHECK_REQUIRED` · `ENTRY_DENIED`로 정해졌어요. 웹 화면 코드도 같은 이름을 써야 해요.
- 오류 응답은 `code` 기준으로 문구를 고르면 앱과 같아져요.
