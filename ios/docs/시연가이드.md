# 시연 영상 촬영 가이드 (사용자 앱)

시연은 프론트 · 백엔드 연동 후 일주일 뒤에 찍는다. 회원가입을 빼고 모든 화면을 보여 준다.

## 1. 어느 쪽으로 찍을지

| | 실서버 (기본) | 목업 |
| --- | --- | --- |
| 설정 | `PawFit/Config/Debug.xcconfig` 그대로 | `Local.xcconfig`에 `PAWFIT_USE_MOCK_API = YES` |
| 데이터 | 백엔드 더미 데이터 (보호자 계정 · 반려견 · 매장 · 이벤트) | 앱 안 고정 데이터 (몽이 · 콩이, 성수동 8곳, 스탬프 3/10) |
| 계정 | 백엔드가 준 보호자 계정 | 010-1234-5678 / pawfit!123 |
| 준비 | 촬영 1~2분 전에 서버 깨우기 (아래) | 없음 |

실서버로 찍고, 서버가 안 될 때를 대비해 목업으로 한 번 더 찍어 두면 안전하다.

### 실서버 깨우기
Render 무료 서버는 잠들어 있으면 첫 요청이 30~60초 걸린다. 촬영 직전에 브라우저로
`https://pawfit-api.onrender.com/actuator/health`를 열어 `UP`이 보이면 시작한다.

## 2. 시뮬레이터 준비

```bash
cd FE/ios && xcodegen generate && open PawFit.xcodeproj   # ⌘R, iPhone 16
```

- 위치: 시뮬레이터 메뉴 **Features › Location › Custom Location…** → 37.5446, 127.0557 (성수동)
- 화면 녹화: `xcrun simctl io booted recordVideo ~/Desktop/pawfit.mov` → 끝낼 때 Ctrl+C
- 상태 표시줄 정리: `xcrun simctl status_bar booted override --time 9:41 --batteryLevel 100 --cellularBars 4`
- 예방접종 서류 · QR 사진은 미리 시뮬레이터 사진 앱에 끌어다 놓는다(사진에서 고르기).

## 3. 촬영 순서 (약 3분)

1. **시작 → 로그인** — 휴대폰 번호 · 비밀번호, 틀린 비밀번호 오류 한 번 보여 주기
2. **지도** — 내 위치 주변 핀 4색, 카테고리 칩, 목록 시트를 올려 '입장 가능/준비 필요' 전환
3. **반려견 기준 바꾸기** — 상단 반려견 메뉴 → 몽이 · 콩이 · 함께 가요 → 핀 색이 바뀌는 것
4. **업체 상세** — 입장 가능 · 준비 필요 · 입장 불가 · 확인 필요 각각 하나씩, 조건 표와 [가기 전에 확인] 시트, 길찾기
5. **챗봇** — 예시 질문 "FF카페에 콩이 데려가도 돼?" → 매장 카드 → [지도에서 보기]로 상세 이동, "콩이 프로필에 유모차 추가" 칩
6. **반려견** — 마이 › 내 반려견 › 콩이 수정 (유모차 켜기) → 지도에서 FF카페가 '입장 가능'으로 바뀌는 것
7. **반려견 등록** — 내 반려견 › 반려견 추가 → 3단계 → 프로필 완성
8. **예방접종 증빙** — 서류 올리기 → AI 확인 중 → 결과 → 내용 고치기 → 운영자 확인 중
9. **댕댕로드** — 마이 › 댕댕로드 → QR로 방문 인증 → 스탬프 애니메이션 → (10곳이면) 추첨 응모 → 응모 완료
10. **마이** — 계정 관리(이름 · 배송지), 알림 설정, 로그아웃

## 4. 백엔드 더미 데이터에 있어야 하는 것

- 보호자 계정 1개 (휴대폰 번호 · 비밀번호)
- 반려견 2마리: 소형(5kg 전후, 유모차 · 이동장 · 매너벨트) · 중형(10kg 전후, 매너벨트만) — '함께 가요'에서 결과가 갈리도록
- 시연 위치(성수동) 반경 1km 안 매장 6~10곳, 판정이 4가지 모두 나오게
  - 입장 가능: 제한 없음 / 준비 필요: 유모차 필수 / 입장 불가: 5kg 이하 / 확인 필요: 정책 미확인
- 진행 중 댕댕로드 이벤트 1개 + 참여 매장 QR 토큰 몇 개 (QR 이미지로 만들어 두기). 스탬프가 9개쯤 쌓인 상태면 응모까지 한 번에 보여 줄 수 있음
- 예방접종 기록 1건(확인 완료) — 다른 1마리는 서류 없음 상태
- 챗봇: 예시 질문 5개에 답이 나오는지 미리 확인

## 5. 막히면

| 증상 | 확인 |
| --- | --- |
| "인터넷 연결을 확인해 주세요" | 서버가 잠들었거나 꺼짐 → 1의 health 확인 |
| 로그인 후 바로 로그인 화면으로 돌아옴 | 토큰 갱신 실패 → 계정 상태 확인, 앱 삭제 후 다시 설치 |
| 지도에 핀이 없음 | 시뮬레이터 위치가 성수동인지, 더미 매장 좌표 확인 |
| QR이 안 읽힘 | 시뮬레이터는 카메라가 없어서 **사진에서 QR 고르기**로 |
